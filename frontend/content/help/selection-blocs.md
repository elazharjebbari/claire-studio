# Sélection multi-blocs

Au-delà de la sélection de phrases (Shift / ⌘-clic), CLAIRE Studio permet de
sélectionner plusieurs **blocs** (clauses) d'un coup pour les annoter ensemble.

## Sélectionner une plage de blocs

- Placez le curseur sur une phrase, **maintenez le bouton DROIT** de la souris,
  puis **glissez** vers le haut ou le bas sur d'autres phrases.
- À mesure que vous glissez, un **tooltip** suit le curseur et indique le nombre
  de blocs couverts : « N bloc(s) sélectionné(s) ».
- **Relâchez** le bouton droit pour finaliser la sélection : tous les blocs
  (clauses) traversés du point de départ au point d'arrivée sont retenus.

> Un clic-droit **sans déplacement** ne sélectionne pas de blocs : il ouvre le
> menu d'annotation de la phrase, comme d'habitude.

## Annoter les blocs sélectionnés

Une fois une sélection de blocs active, une **barre flottante** apparaît en bas
du document :

- **« N bloc(s) »** rappelle le nombre de clauses sélectionnées.
- **« Annoter les blocs »** ouvre la palette de thèmes ; le thème choisi est
  appliqué à **toutes** les clauses sélectionnées en une seule action.
- **« Effacer »** vide la sélection.

La sélection de blocs n'interfère pas avec le clic simple (focus / pose d'ancre),
ni avec la sélection de phrases : ce sont des canaux distincts.
