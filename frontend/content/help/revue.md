# Revue

Le mode revue (`/review/[id]`) permet à un **relecteur** d'évaluer une annotation
sans l'éditer : lecture, commentaires et notation.

## Notation

Le relecteur attribue une **note** à l'annotation et peut consigner une décision
(par exemple : acceptée, à corriger, rejetée). La certitude globale renseignée par
l'annotateur éclaire cette évaluation.

## Décisions

- **Commenter** : ouvrir un fil sur une clause pour pointer un problème précis.
- **Noter** : évaluer la qualité globale de l'annotation.
- **Décider** : statuer sur le sort de l'annotation (validation, renvoi pour
  correction).

> Le relecteur a un accès en **lecture + commentaire** au workspace, mais ne
> modifie pas les clauses de l'annotateur.
