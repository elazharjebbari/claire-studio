# Commentaires

Les commentaires servent à **justifier un choix** d'annotation ou à dialoguer avec
les relecteurs. Ils sont attachés à une clause ou une phrase.

## Ouvrir un fil

- Sélectionnez une clause, puis appuyez sur la touche `C`, ou utilisez le **fil de
  commentaires** dans l'inspecteur.
- Saisissez votre justification, puis envoyez. Le fil conserve l'historique des
  échanges.

## Résolution

Un commentaire peut être marqué **résolu** une fois la question tranchée, ce qui
le distingue des discussions encore ouvertes.

> Le fil de commentaires n'apparaît que lorsqu'une clause est sélectionnée :
> sélectionnez d'abord une clause dans le document ou le plan.
