# Injustice CLAUDETTE

CLAIRE Studio intègre par défaut les **labels d'injustice du corpus CLAUDETTE**
(UNFAIR-ToS). Un overlay surligne directement dans le document les phrases
marquées comme potentiellement injustes, avec leur catégorie et leur niveau.

## Activer l'overlay

Dans le panneau Plan, cochez **« Injustice CLAUDETTE »**. Les phrases concernées
sont surlignées ; une info-bulle indique la catégorie et le niveau au survol.

## Catégories

| Code | Catégorie |
|---|---|
| `A` | Arbitrage |
| `CH` | Modification unilatérale |
| `CR` | Suppression unilatérale de contenu |
| `J` | Choix de juridiction |
| `LAW` | Droit applicable |
| `LTD` | Limitation de responsabilité |
| `TER` | Résiliation unilatérale |
| `USE` | Usage des données contractuel |

## Niveaux

L'injustice est graduée par niveau (par exemple 1 = potentiellement injuste,
2 = clairement injuste, 3 = manifestement injuste). Le niveau module l'intensité
du surlignage.

> Cet overlay est une **aide au repérage**, pas une décision imposée : il met en
> évidence les zones sensibles sans préjuger de votre annotation.
