# Pactiva → Détection d'anomalies dans les ToS : programme de recherche & propositions JURIX

**Objet.** Un dossier **plus ambitieux et plus inventif** que
[`../pactiva-jurix-2026/`](../pactiva-jurix-2026/00_README.md), recentré sur **le but réel du
projet et de CLAUDETTE : la détection d'anomalies**. L'idée maîtresse : la phase d'annotation Pactiva
(clause + thème + **nature déontique** + certitude + rationale + labels d'abusivité) n'est pas une fin
mais le **substrat** qui transforme chaque contrat en **graphe de connaissances déontique**, sur lequel
la détection d'anomalies devient du **raisonnement de graphe** — unifiant quatre familles d'anomalies
que la littérature traite séparément, **y compris les anomalies d'annotateurs**.

**Date :** 1ᵉʳ août 2026 · **Auteur pressenti :** Ahmed El Azhar Jebbari (LORIA) · **Cible :** JURIX
2026 (Toulouse, ~5 sept. 2026) + programme de recherche pluriannuel.

## Rapport avec le dossier précédent

Le dossier [`../pactiva-jurix-2026/`](../pactiva-jurix-2026/00_README.md) restait **centré
annotation** (le « mur du κ » + une ressource enrichie). Celui-ci est **centré détection d'anomalies**
et **forward-looking** : il intègre la **segmentation thématique de clause**, le **graphe de
connaissances**, des **algorithmes récents de détection d'anomalies** (graphe + annotateurs), et fait
du « mur du κ » un **sous-résultat** (la mesure de l'ambiguïté irréductible = niveau L4). Les deux se
complètent ; ce dossier-ci porte la **force de proposition principale**.
