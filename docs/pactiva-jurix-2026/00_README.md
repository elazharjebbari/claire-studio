# Pactiva → JURIX 2026 — dossier de cadrage scientifique et propositions d'articles

**Objet.** Inscrire la phase d'annotation menée sur la plateforme **Pactiva** (ex-CLAIRE Studio)
dans un cadre de recherche défendable, puis proposer et comparer des sujets d'article pour la
conférence **JURIX 2026** (Toulouse, IRIT, 8–10 décembre 2026 ; soumission ~5 septembre 2026).

**Date :** 1ᵉʳ août 2026 · **Auteur pressenti :** Ahmed El Azhar Jebbari (LORIA, Université de
Lorraine ; encadrement J.-C. Lamirel) · **Statut :** document d'aide à la décision.

## Contenu du dossier

| Document | Objet |
