# Vision

une interface de résolution **collaborative, rapide et lisible**. Vitesse de décision et
lisibilité (mise en page « contrat ») priment ; le moteur pré-mâche les cas simples, l'humain
tranche les cas risqués. Traçabilité totale (qui a arbitré quoi), temps réel, export gold.
