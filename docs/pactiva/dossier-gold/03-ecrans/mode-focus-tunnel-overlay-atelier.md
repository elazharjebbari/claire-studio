# Mode Focus tunnel (overlay atelier)

## Fonctionnalités PRIMAIRES
- Un seul conflit au centre, phrases mises en avant façon contrat (catégorie en titre), options de vote empilées SOUS le curseur
- Avancer = la carte suivante glisse exactement sous le curseur (translateY sobre) ; accords absolus pré-cochés passés en rafale
- Raccourcis Espace/Entrée (majoritaire pondéré), 1..9 (option), n/p (conflit ±), u (annuler)

## Fonctionnalités SECONDAIRES (navigation / ergonomie / vitesse)
- Mini-map/ToC contextuelle réduite sur le côté
- Sortie f/Échap revient à la vue contrat SUR le conflit courant
- État du mode mémorisé en prefs par document
