 RÈGLES
 • Le refuge n'est JAMAIS secondaire (back-end) → grisé / non sélectionnable
   dans la palette « ＋ thème secondaire ».
 • Toggle = annulation : OFF re-masque les secondaires sans les détruire ; ON
   les réaffiche. Undo/redo global en filet de sécurité.
 • Feedback de bascule < 200 ms (cf. animations.md : transition mono↔multi).
 • La couleur de ⚡ / ★ / ✎ encode l'état (vert validé · ambre à valider) ;
   la FORME ne change pas (provenance stable).
