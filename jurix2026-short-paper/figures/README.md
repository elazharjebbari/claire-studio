# figures/

Formats acceptés par IOS Press : **PDF, EPS, PNG, JPG** (PDF vectoriel de préférence).
Lettrage dans les figures : sans-serif (Helvetica/Arial), **6 pt minimum** ; polices embarquées.
La couleur est conservée dans l'ebook ; l'impression couleur dépend de l'éditeur du volume —
concevoir des figures lisibles en niveaux de gris.

`example-figure.pdf` est un placeholder construit depuis `example-figure.tex`
(`pdflatex example-figure.tex` dans ce dossier). Supprimer les deux fichiers dès que de
vraies figures existent.
